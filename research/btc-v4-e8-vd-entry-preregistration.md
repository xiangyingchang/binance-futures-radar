## 1. 研究问题

E7 发现每日 L3 入场在 Bear Lock 对冲期内会以 1.5x override 优先级顶掉 0.0x 空头保护，E7 记录了一个尚未检验的 V-D 猜想：Bear Lock 未激活时允许每日入场，对冲期内不让每日入场覆盖保护。本实验对称比较 V-A 与两个 V-D 版本，不预设任一方正确。

## 2. 预先固定的变体

| 变体 | 非周日且 Bear Lock=false | 非周日且 Bear Lock=true | 周日 | L3 校准/退出/kill |
|---|---|---|---|---|
| V-A（现行） | 不入场 | 不入场 | 按 gate 入场 | 周日 |
| V-D1 | 按 gate 每日入场 | 退回周日入场 | 按 gate 入场 | 周日 |
| V-D2 | 按 gate 每日入场 | 完全禁止入场 | Bear Lock=false 时按 gate 入场；Bear Lock=true 时禁止 | 周日 |

精确定义：V-D1 的入场条件为 `gate && (!bearLock || isSunday)`；V-D2 的入场条件为 `gate && !bearLock`。这里的 `isSunday` 是 E7 引擎中执行日 `i` 的周日判断，指标来自 `d=i-1` 的 T-1 收盘。V-D1/V-D2 的 exit 和 182 天 kill switch 均只在周日判定；V-D2 不是“Bear Lock 结束后补入场”，而是等后续非周日 gate 重新成立或按定义在周日也不入场，直到下一次允许的非 Bear Lock 日。

三组共用且不变：

- 确认门：`AHR999 < 0.40` 且 `dd365 <= -20%`。
- L3 目标上限：`1.5x`。
- L3 退出滞后线：`AHR999 >= 0.45`，周日判定。
- 182 天 kill switch，周日判定。
- override 交还后立即应用当日 L2 结果；优先级仍为 L3 override > L2 Bear Lock > 1.0x。
- L2 每日 Bear Lock + 25% breaker。
- 所有信号使用 T-1 收盘；不使用未来价格决定当日状态。
- L1 周日 DCA 六档和弹药池完全相同。
- 手续费、数据、历史窗口、现金流和随机种子完全相同。

唯一实验变量是 L3 入场规则；不改变已有 V-A/V-B/V-C 模式的逻辑。

## 3. 引擎、数据和窗口

直接复用 E7 引擎 `scripts/btc-v4-e7-l3-frequency-engine.js`，仅在 `l3Mode` 中新增 `vd1`、`vd2` 两个入场模式；已有 `weekly`、`enterDaily`、`fullDaily`、`off` 的行为不得改变。E7 runner 的 DCA/线性日频引擎作为唯一主回测口径，不另造一个等价实现。

数据使用 Coin Metrics Community 的 BTC `PriceUSD` 日数据和 AHR999 官方数据集核验。价格截止日固定为 E7 的 `2026-05-23`，窗口固定为 E7 的 `2011-07-19` 至 `2026-05-23`；若需重新下载，必须记录来源 URL、SHA-256、首尾日期、行数、重复日期和缺失日。AHR 复现误差必须记录，不能把数据缺口当作 0。

Bootstrap 固定使用 E7 同款年块有放回重抽样：10,000 次，随机种子 `20260903`。不得根据结果改变块长度、种子、窗口或阈值。

## 4. 前置盘点：实验信息量

在正式比较三组前，先列出所有满足以下条件的 T-1 信号日：

`AHR999 < 0.40 && dd365 <= -20% && BearLock == false && 执行日不是周日`

报告同时列信号日和首个受影响收益日。该集合是 V-D 与 V-A 唯一可能在“当天是否新入场”上分叉的日子。每个日期计算从信号日收盘起算的 30/90 日 BTC 价格变化。

若分叉日数量为 0，或三组完整路径逐日状态与最终结果完全相同，立即判定“无差异、维持 V-A”，不继续制造统计噪声；报告必须写明实验无信息量。

## 5. 必答问题

### (a) 分叉日清单

逐日列出日期、AHR、dd365、Bear Lock、信号/受影响日期、V-A/V-D1/V-D2 当日暴露，以及 30/90 日价格变化。将“每日方案可能获得的机会成本”与“进入对冲保护后的保护损失”分列；不得只展示有利于某一规则的方向。

### (b) 入场时点差异

以共同深水 episode 对齐，分别列 V-D1、V-D2 相对 V-A 的：入场日期、提前/推迟天数、入场参考价差、从候选入场到 V-A 入场期间的最大价格回撤和 1.5x 暴露收益/损失；V-A 未入场的 episode 单列为机会成本。

同时统计候选与 V-A 的暴露重叠区间：

- 候选为 1.5x、V-A 为 1.0x：记为候选承担的额外机会/风险暴露；
- 候选为 1.5x、V-A 为 0.0x：记为“保护损失”日，计算价格收益和线性 overlay 相对损益；
- 两列并排报告，不允许用“每日抓反弹”或“周日避免下跌”单边概括。

### (c) Episode 级 leave-one-out

沿用 E7 的屏蔽法：以 V-A 的实际 override episode 为屏蔽单位，把该 episode 的 AHR 在其 entry 前一日到 exit 日的入场条件屏蔽，再分别重算 V-A、V-D1、V-D2。逐 episode 给出候选相对 V-A 的全系统超额差和方向；若整体方向为正，任何屏蔽使其变为非正即算翻转；若整体方向为负，任何屏蔽使其变为非负即算翻转。

### (d) 入场后回撤与 E2

对每个变体逐 episode 统计入场后最大收盘跌幅，并汇总样本数、P50、P90、P95、最深值；与 E2 的 40%/50%/60% 合成压力假设对照。若 V-D1/V-D2 尾部更深，必须明确说明 1.5x 在 E2 验收切片（10% 维持保证金、20% wick、高资金费率）是否仍无爆仓且达到最小余量 ≥3x；不得把线性 E7 结果直接当作清偿力证明。优先复用已冻结的 E2 结果，不修改 E2 参数。

## 6. 晋级判据（写死）

V-D1 或 V-D2 只有同时满足以下条件，才获得“可供人工考虑替代 V-A”的资格：

1. 全史相对 V-A 的超额差为正，且实测候选/V-A 终值差严格超过 E7 同款年块 bootstrap 的 P90 噪声上界；
2. LOO 全掩码不翻转；
3. 入场后回撤尾部不劣于 V-A；若尾部更深，则 E2 口径下 1.5x 清偿力不得被侵蚀：验收切片无爆仓、最小余量 ≥3x，且不低于 V-A 对应余量。

任一条件不满足，维持 V-A，并在结论中只使用下列三种理由之一：

- `无差异`：分叉日为零或完整路径相同，实验没有信息量；
- `证据不足`：候选未通过 bootstrap、LOO 或尾部/清偿力联合门槛，不能支持改规则；
- `V-D 更差`：候选相对 V-A 的全史结果为负且证据方向一致，明确记录为更差，但仍不把它表述为“周日已被证明最优”。

若候选胜出但优势只由单一分叉日驱动，固定判定为 `证据不足`，不晋级。

## 7. 诚实与执行边界

深水 episode 约为个位数，分叉日可能更少；所有统计结论标注为方向性证据。不得改动生产 cron、Forward Test ledger、V4 冻结参数或 E7 已有产物。结果只落研究分支并提交/推送，最终结论等待人工裁决。
