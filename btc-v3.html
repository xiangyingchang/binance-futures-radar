HOW IT WORKS

策略说明

完整设计文档 ↗
核心逻辑：Trend 决定能不能承担风险，Valuation 决定想承担多少，Volatility 和 Margin 决定最多允许多少。V3 不是“跌了就抄底”的网格，也不是长期 2x BTC。目标是长期保持 BTC Core，再用 COIN-M Futures Overlay 动态调节净 BTC Exposure。
01 · TREND趋势优先

三个条件各 1 分：Close > MA200、EMA15 > EMA30、MA200 30D slope > 0。

02 · VALUATION低估只做加成

365D 回撤或 MA200 偏离判断 cheap / very cheap，但只有趋势改善后才能提高敞口。

03 · VOLATILITY高波动自动降杠杆

30D RV 计算 Vol Cap：0.60 / RV30，避免在最剧烈的暴跌阶段机械放大仓位。

04 · MARGIN风险上限

当前生产环境固定 Margin Cap 1.50x。未来超过 1.50x 必须经过独立的账户保证金审查。

关键保护规则

  • Bear Lock：Close < MA200 且 MA200 30D slope < 0 → 目标 0x，经济上对冲 BTC Core。
  • Cheap：365D drawdown ≤ -20% 或 MA200 deviation ≤ -10%。
  • Very Cheap：365D drawdown ≤ -35% 或 MA200 deviation ≤ -20%。
  • 趋势确认后加仓：Trend=2 + Cheap → 最多 1.25x；Trend=3 + Cheap → 最多 1.50x。
  • 2x：只保留研究权限，当前生产 Margin Cap 会限制在 1.50x。
