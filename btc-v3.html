策略说明

完整设计文档 ↗
核心逻辑：趋势决定能不能承担风险，估值决定想承担多少，波动率和保证金决定最多允许多少。V3 不是“跌了就抄底”的网格，也不是长期 2x BTC。目标是长期保持 BTC 核心仓位，再用 COIN-M 期货叠加动态调节 BTC 净敞口。
01 · 趋势趋势优先

三个条件各 1 分：收盘价 > MA200、EMA15 > EMA30、MA200 30日斜率 > 0。

02 · 估值低估只做加成

365日回撤或 MA200 偏离判断低估 / 极度低估，但只有趋势改善后才能提高敞口。

03 · 波动率高波动自动降杠杆

用 30日实现波动率计算波动率上限：0.60 / RV30，避免在最剧烈的暴跌阶段机械放大仓位。

04 · 保证金风险上限

当前生产环境固定保证金上限 1.50x。未来超过 1.50x 必须经过独立的账户保证金审查。

趋势评分 → 基础敞口

0 / 30.50x防守
1 / 30.75x偏防守
2 / 31.00x中性
3 / 31.25x进攻

关键保护规则

  • 熊市锁定：收盘价 < MA200 且 MA200 30日斜率 < 0 → 目标 0x，经济上对冲 BTC 核心仓位。
  • 低估：365日回撤 ≤ -20% 或 MA200 偏离 ≤ -10%。
  • 极度低估：365日回撤 ≤ -35% 或 MA200 偏离 ≤ -20%。
  • 趋势确认后加仓：趋势评分=2 + 低估 → 最多 1.25x；趋势评分=3 + 低估 → 最多 1.50x。
  • 2x：只保留研究权限，当前生产保证金上限会限制在 1.50x。
